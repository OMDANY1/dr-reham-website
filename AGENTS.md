# Implementation contract

## Priority
Explicit client instructions > this file > docs/00-BRIEF.md > specific route specs > reference snippets. Flag contradictions; do not silently change the visual direction. These files are instructions, not evidence for new medical claims.

## Required reading
Read all numbered docs, relevant route specs, content records and asset README before implementation. Start with the sources ledger. Preserve this package; generate app code under website/.

## Hard constraints
1. Arabic-first RTL, no doctor portrait dependency, no fabricated portrait.
2. Only sky/cyan/white family plus readable deep blue text. No burgundy, purple, gold, generic rainbow gradients.
3. Preserve exact uploaded logo geometry. CSS masking is preferred. Do not generate a replacement monogram or label an automated trace as original vector artwork.
4. Never invent credentials, counts, prices, procedures, reviews, phone numbers, clinical results or booking URLs.
5. Do not convert Instagram follower count into a trust metric. Do not imply a hospital endorsement from a certificate.
6. No dummy success messages, dead buttons, href="#", fake booking confirmations or consent checkboxes with no effect.
7. No unnecessary dashboard, auth, database or patient data collection. No production publication without client instruction.
8. Keep static content server-rendered. Animate only where specified. Respect reduced motion, focus, keyboard and touch.
9. Default to completing reversible implementation choices. Unknown clinical facts block those records, not the whole design.
10. New dependencies must be justified. Verify exact APIs and versions against official documentation when implementing; lock dependencies. This package does not claim a tested version matrix.

## Completion
All specified routes have an intentional rendered state, including unpublished detail routes returning 404; no draft clinical content leaks into sitemap, schema or metadata. QA evidence and remaining integration gaps are required. Do not call a preview production-ready while booking destination, professional title, privacy policy or legal business identity is unresolved.
