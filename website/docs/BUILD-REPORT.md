## 2. ملخص التطوير وإثراء المحتوى والواجهة

1. **إضافة تاب «المقالات» (`/ar/journal` و`/ar/journal/[slug]`):**
   - إظهار تاب **«المقالات»** في شريط التنقل على الديسكتوب وقائمة الجوال وفي التذييل (`Footer`)، مع إبراز حالة التاب النشط (`aria-current="page"`) باللون التيل `#0B7A9A`.
2. **تصميم صفحة المقالات كمجلة طبية مصغرة (`/ar/journal`):**
   - عنوان «تفاصيل تستحق المعرفة» ووصف «قراءات مبسّطة حول العين والجفون والاستعداد للاستشارة.»
   - **مقال مميز في البداية** بصورة تحريرية كبيرة، وعنوان كحلي واضح، وملخص، ووقت قراءة محسوب تلقائيًا، وشارة «مسودة للمراجعة» بنص تيل وحدود منقطة `#0B7A9A`، وزر «قراءة المقال»، مع عدم تكراره في الشبكة أدناه.
   - **شبكة مقالات بصور تحريرية متنوعة ومتناسقة** (٦ أصول فوتوغرافية مخصصة للمقالات) مع فلاتر تصنيف («العين والجفون»، «حول العين»، «قبل الاستشارة») وبحث فوري في العناوين والملخصات يعملان معًا، وحالة واضحة عند عدم وجود نتائج مع زر إعادة ضبط.
3. **تجهيز ٦ مسودات عربية مكتملة للمعاينة وفصل المعاينة عن النشر:**
   - تم إعداد ٦ مقالات عربية مكتملة (`status: "draft"`) مبنية على مراجع مؤسسية موثقة (`AAO`, `NHS`, `Mayo Clinic`) مع تسجيل روابط المصادر الفعلية في نهاية كل مقال.
   - لم تُنسب الكتابة أو المراجعة للدكتورة دون اعتماد فعلي (`author: null, reviewedBy: null, reviewedAt: null`)، وتظهر شارة «مسودة للمراجعة» في وضع المعاينة فقط، بينما تمنع بوابة `isPublicArticle()` تسرب أي مسودة إلى `sitemap.xml` أو بيانات `Schema.org` أو وضع الإنتاج العام.
4. **قالب صفحة المقال الداخلية (`/ar/journal/[slug]`):**
   - مسار تنقل واضح (`الرئيسية / المقالات / عنوان المقال`)، وصورة افتتاحية بدون تلوين فوقها، وعمود قراءة مريح (`62ch`)، وعناوين فرعية كحلية وقوائم نقطية، وفهرس تنقل داخلي (`فهرس المقال`) بخط رأسي تيل، والمصادر المؤسسية الموثقة، وزر مشاركة يعمل مع نسخ الرابط كبديل (`نسخ الرابط` -> `تم نسخ الرابط`)، ومقالات مرتبطة بحسب التصنيف، ودعوة هادئة للاستفسار.
5. **الصفحة الرئيسية (`/ar`) بـ ٨ أقسام متمايزة التكوين:**
   1. الافتتاحية الفوتوغرافية (`Hero`) مع عبارة «بتفاصيل نظرتك» بالتيل `#0B7A9A` وخط رملي واحد أسفل العنوان الرئيسي (`56px × 3px`, `#C9A27A`).
   2. التعريف الموجز بالدكتورة (`Doctor Brief`).
   3. قسم التخصص (`Specialty Showcase`).
   4. قسم **«قبل الاستشارة»** بثلاث خطوات متصلة بخط `#B8D4E3` ودوائر أرقام تيل `#0B7A9A` بنص أبيض وكروت `#F4F9FC` بحدود `#B8D4E3`.
   5. قسم **«من المقالات»** (مقال كبير بجانب مقالتين أصغر مع وسم تصنيف `#E6F1F7` بنص كحلي ورابط «قراءة المقال» بالتيل وتحته خط تيل).
   6. قسم **«تعرّف على أسلوب المحتوى»** بخطوط رأسية تيل `#0B7A9A` للتعريف بالطرح التوعوي وحساب إنستجرام الرسمي (`@dr.rehamdq`).
   7. قسم **«أسئلة عملية مختصرة»** بكروت `#F4F9FC` وحدود `#B8D4E3`.
   8. قسم التواصل الختامي **«لنبدأ باستفسارك»** بتدرج من `#0B7A9A` إلى `#086680` بدون الشريط السماوي القديم أعلى القسم، وعنوان رئيسي أبيض، وعنوان فرعي «التواصل المباشر» بلون `#E3C9A5`، وفقرة بلون `rgba(255, 255, 255, 0.92)`، وزر أبيض بنص كحلي `#0F2A3D`.
