- **المشروع:** موقع د. ريهام القحطاني — طب وجراحة تجميل العيون والجفون (الرياض)
- **الاتجاه الإبداعي:** تصميم فوتوغرافي تحريري مخصص مع مجلة طبية مصغرة («تفاصيل تستحق المعرفة») وصفحة رئيسية غنية ومتوازنة
- **تاريخ التنفيذ والمراجعة:** `2026-10-29`
- **وضع التشغيل الحالي:** `preview` (`noindex, nofollow`) — يعرض مسودات المقالات الست المكتملة للمراجعة والتقييم عبر إعداد الخادم (`siteConfig.mode === "preview" && siteConfig.enablePreviewDrafts`) مع إبقاء بوابة الاعتماد الصارمة للإنتاج العام وخريطة الموقع.

## 1. ملخص التطوير وإثراء المحتوى والواجهة

1. **إضافة تاب «المقالات» (`/ar/journal` و`/ar/journal/[slug]`):**
   - استبدال تسمية «المعرفة» بـ**«المقالات»** وإظهارها في شريط التنقل على الديسكتوب وقائمة الجوال وفي التذييل (`Footer`)، مع إبراز حالة التاب النشط (`aria-current="page"`) في صفحة فهرس المقالات وجميع صفحات المقالات الداخلية.
2. **تصميم صفحة المقالات كمجلة طبية مصغرة (`/ar/journal`):**
   - عنوان «تفاصيل تستحق المعرفة» ووصف «قراءات مبسّطة حول العين والجفون والاستعداد للاستشارة.»
   - **مقال مميز في البداية** بصورة تحريرية كبيرة، وعنوان واضح، وملخص، ووقت قراءة محسوب تلقائيًا، وشارة «مسودة للمراجعة»، وزر «قراءة المقال»، مع عدم تكراره في الشبكة أدناه.
   - **شبكة مقالات بصور تحريرية متنوعة ومتناسقة** (٦ أصول فوتوغرافية مخصصة للمقالات) مع فلاتر تصنيف («العين والجفون»، «حول العين»، «قبل الاستشارة») وبحث فوري في العناوين والملخصات يعملان معًا، وحالة واضحة عند عدم وجود نتائج مع زر إعادة ضبط.
3. **تجهيز ٦ مسودات عربية مكتملة للمعاينة وفصل المعاينة عن النشر:**
   - تم إعداد ٦ مقالات عربية مكتملة (`status: "draft"`) مبنية على مراجع مؤسسية موثقة (`AAO`, `NHS`, `Mayo Clinic`) مع تسجيل روابط المصادر الفعلية في نهاية كل مقال.
   - لم تُنسب الكتابة أو المراجعة للدكتورة دون اعتماد فعلي (`author: null, reviewedBy: null, reviewedAt: null`)، وتظهر شارة «مسودة للمراجعة» في وضع المعاينة فقط، بينما تمنع بوابة `isPublicArticle()` تسرب أي مسودة إلى `sitemap.xml` أو بيانات `Schema.org` أو وضع الإنتاج العام.
4. **قالب صفحة المقال الداخلية (`/ar/journal/[slug]`):**
   - مسار تنقل واضح (`الرئيسية / المقالات / عنوان المقال`)، وصورة افتتاحية، وعمود قراءة مريح (`62ch`)، وعناوين فرعية وقوائم نقطية، وفهرس تنقل داخلي (`فهرس المقال`)، والمصادر المؤسسية الموثقة، وزر مشاركة يعمل مع نسخ الرابط كبديل (`نسخ الرابط` -> `تم نسخ الرابط`)، ومقالات مرتبطة بحسب التصنيف، ودعوة هادئة للاستفسار.
5. **إثراء الصفحة الرئيسية (`/ar`) بـ ٨ أقسام متمايزة التكوين وضبط المسافات الرأسية (`64–88px` ديسكتوب / `40–56px` موبايل):**
   1. الافتتاحية الفوتوغرافية الحالية (`Hero`).
   2. التعريف الموجز بالدكتورة (`Doctor Brief`).
   3. قسم التخصص (`Specialty Showcase`).
   4. قسم جديد **«قبل الاستشارة»** بثلاث خطوات متصلة ومرتبة.
   5. قسم بارز **«من المقالات»** (مقال كبير بجانب مقالتين أصغر مع زر «جميع المقالات»).
   6. قسم **«تعرّف على أسلوب المحتوى»** للتعريف بالطرح التوعوي وحساب إنستجرام الرسمي (`@dr.rehamdq`).
   7. قسم **«أسئلة عملية مختصرة»** (٤ أسئلة عملية قابلة للفتح).
   8. دعوة التواصل الختامية («لنبدأ باستفسارك») والتذييل.
