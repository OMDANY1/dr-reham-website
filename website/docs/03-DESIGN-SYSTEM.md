# Design system

## 1. نظام الألوان المعتمد (Approved Color System)
هذه اللوحة هي المرجع الوحيد لألوان الواجهة في جميع الصفحات والمكونات المشتركة:

| Token | Hex | Use |
|---|---|---|
| `--color-navy` | `#0F2A3D` | العناوين واللوجو في الهيدر والفوتر والصفحات |
| `--color-teal` | `#0B7A9A` | اللون المميز للأزرار والروابط والتفاصيل وعبارة «بتفاصيل نظرتك» |
| `--color-teal-hover` | `#086680` | تفاعل الأزرار الأساسية (`hover` / `active`) وتدرج قسم التواصل |
| `--color-sand` | `#C9A27A` | التفصيلة الرملية الوحيدة أسفل عنوان الـHero (`56px × 3px`) |
| `--color-sand-light` | `#E3C9A5` | العنوان الفرعي «التواصل المباشر» على خلفية التيل |
| `--color-paragraph` | `#475569` | الفقرات ونصوص الفوتر |
| `--color-secondary` | `#64748B` | النصوص الثانوية والتفاصيل المساعدة |
| `--color-page-bg` | `#F8FBFD` | خلفية الصفحة الأساسية |
| `--color-card-bg` | `#F4F9FC` | خلفية كروت المقالات والخطوات والأسئلة |
| `--color-border` | `#B8D4E3` | الحدود (`1.5px`) وخطوط الربط بين الخطوات وحد الفوتر العلوي |
| `--color-tag-bg` | `#E6F1F7` | خلفية وسوم التصنيفات مع نص كحلي `#0F2A3D` |
| `--color-white` | `#FFFFFF` | الأبيض الناصع (الهيدر، قائمة الجوال، الأزرار الثانوية، ونص الأزرار الأساسية) |

## 2. الطباعة والخطوط (Typography)
- الخط العربي: `IBM Plex Sans Arabic` محلي (`WOFF2` داخل `public/fonts/`) بأوزان 400 و500 و600 و700، مع تباين حقيقي وواضح بين العناوين والمتن.
- **العنوان الرئيسي (Hero H1):** `64–80px` للديسكتوب (`clamp(3.85rem, 4.8vw + 0.8rem, 4.85rem)`) و`38–46px` للموبايل (`clamp(2.375rem, 5.5vw + 1rem, 2.875rem)`), بارتفاع سطر متماسك `1.18–1.24`.
- **العناوين الفرعية (Section H2 / H3):** قوية ومقروءة (`32–48px` للعناوين الرئيسية للأقسام، و`22–28px` للعناوين الفرعية)، وليست صغيرة وسط فراغات ضخمة.
- **النص الأساسي (Body):** `17–19px` (`clamp(1.0625rem, 0.25vw + 1rem, 1.1875rem)`), بارتفاع سطر مريح `1.8`.
- الحفاظ الكامل على اتصال الحروف العربية، ومنع `letter-spacing` أو تحريك الحروف منفصلة.

## 3. الشعار (Logo)
- الملف المرفق `assets/brand/logo-original.png` (`216×188` RGBA) يُعرض عبر `CSS mask-image` و`-webkit-mask-image` باللون الكحلي (`#0F2A3D`) في الهيدر والفوتر والصفحات، أو بالتيل (`#0B7A9A`) أو الأبيض (`#FFFFFF`) عند الحاجة حسب الخلفية، مع الحفاظ على نسبه ووضوحه دون إعادة رسمه.
