# Build site workflow

1. Read START-HERE.md, AGENTS.md, docs, routes and content.
2. Audit workspace; select and verify compatible stable tooling.
3. Build design tokens, logo, responsive shell and hero inside website/.
4. Visually review desktop/mobile composition before repeating patterns.
5. Implement every route and content gate; include real empty/error states.
6. Add restrained motion and semantic metadata.
7. Run QA, fix failures and document evidence in website/docs/BUILD-REPORT.md.
8. Deliver preview and unresolved factual/integration items. Publishing is separate.
