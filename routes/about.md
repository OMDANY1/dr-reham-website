# /ar/about — Editorial Profile

- **تكوين الصفحة:** تصميم تحريري راقٍ يجمع بين الحضور الفوتوغرافي التعبيري لتفاصيل النظرة وبين السرد المهني المقتضب والموثق لد. ريهام القحطاني (طب وجراحة تجميل العيون والجفون — الرياض).
- **المحتوى:** يقتصر على المعلومات المؤكدة فقط (الاسم، التخصص الدقيق، المدينة، ومنهجية العناية بتفاصيل الجفن ومحيط العين) دون اختراع مؤهلات أو سنوات خبرة، ودون إظهار رسائل داخلية توحي بأن الصفحة قيد الإنشاء.
- **الدعوة للتواصل:** تنتهي الصفحة بقسم «لنبدأ باستفسارك» المتصل بوسيلة التواصل المؤكدة.
