# Design system

| white | #FFFFFF | الخلفية الأساسية ومساحات القراءة النظيفة |
| sky-50 | #F4FAFD | خلفية خفيفة جدًا ومحدودة الانتشار |
| sky-100 | #E3F4FB | تمييز بصري ناعم |

## 2. الطباعة والخطوط (Typography)
- الخط العربي: `IBM Plex Sans Arabic` محلي (`WOFF2` داخل `public/fonts/`) بأوزان 400 و500 و600 و700، مع تباين حقيقي وواضح بين العناوين والمتن.
- **العنوان الرئيسي (Hero H1):** `64–80px` للديسكتوب (`clamp(3.85rem, 4.8vw + 0.8rem, 4.85rem)`) و`38–46px` للموبايل (`clamp(2.375rem, 5.5vw + 1rem, 2.875rem)`), بارتفاع سطر متماسك `1.18–1.24`.
- **العناوين الفرعية (Section H2 / H3):** قوية ومقروءة (`32–48px` للعناوين الرئيسية للأقسام، و`22–28px` للعناوين الفرعية)، وليست صغيرة وسط فراغات ضخمة.
- **النص الأساسي (Body):** `17–19px` (`clamp(1.0625rem, 0.25vw + 1rem, 1.1875rem)`), بارتفاع سطر مريح `1.8`.
- الحفاظ الكامل على اتصال الحروف العربية، ومنع `letter-spacing` أو تحريك الحروف منفصلة.

## 3. الشعار (Logo)
- الملف المرفق `assets/brand/logo-original.png` (`216×188` RGBA) يُعرض عبر `CSS mask-image` و`-webkit-mask-image` بلون أزرق داكن (`--ink`) أو سماوي (`--sky-700`) أو أبيض (`--white`) حسب الخلفية، مع الحفاظ على نسبه ووضوحه دون إعادة رسمه.
