# Design system — «للنظرة تفاصيل»

## 1. نظام الألوان والأسطح
- **الأبيض (`#FFFFFF`):** القاعدة الأساسية للافتتاحية، الفصل الثاني، فصل المقالات، وصفحة المجلة.
- **السماوي المتوسط والعميق (`#086888` / `#0A7EA4` / `#E5F5FA`):** يُستخدم بجرأة في مساحة رئيسية مميزة (الفصل الثالث «د. ريهام القحطاني»)، مع درجات فاتحة محصورة في تفاصيل محدودة.
- **الأزرق العميق (`#071E2C` / `#0D2D40`):** للنصوص الأساسية والعناوين والتباين العالي.
- **الفواصل الخطية (`#D3E3EC` / `#0D2D40` بنسبة شفافية خفيفة):** خطوط رفيعة (`1px`) تفصل الصفوف التحريرية بدل إحاطة العناصر ببطاقات مستطيلة متكررة.

## 2. الزوايا والأشكال الهندسية
- **الصور الرئيسية والفرعية:** مستطيلة بحواف مستقيمة (`border-radius: 0` إلى `2px`).
- **الأزرار وحقول الإدخال:** زوايا خفيفة وحادة (`border-radius: 4px`) بدل الأزرار الدائرية (`pill`).

## 3. الطباعة العربية التحريرية
- الخط المحلي `IBM Plex Sans Arabic` بأوزان 400 و500 و600 و700.
- عنوان الافتتاحية «للنظرة / تفاصيل.» بحجم عرض تحريري كبير (`clamp(3.75rem, 7.5vw, 6.75rem)` على الديسكتوب، و`clamp(2.75rem, 11vw, 4rem)` على الموبايل) مع ارتفاع سطر متماسك وعدم قص الكلمات.
- منع التباعد بين الحروف العربية (`letter-spacing: 0`) ومنع فصل الحروف أثناء التحريك.

## 4. الشعار (Logo)
- يُستخدم الشعار الأصلي `assets/brand/logo-original.png` عبر `CSS mask-image` مع تغيير لونه ديناميكيًا حسب الخلفية (أزرق عميق على الخلفية البيضاء، وأبيض ناصع على الأسطح السماوية الداكنة).
