# Build order and handover

1. Audit existing folder; read package. Create local typed content and preview-mode configuration. Record unknowns in website/docs/OPEN-ITEMS.md.
2. Implement tokens, font handling, exact logo mask, layout and accessible navigation. Build root redirect and locale validation.
3. Implement home composition and ContourScene. Review desktop/mobile design, adjust spacing and Arabic wrapping before scaling pages.
4. Implement about, services with detail template/gating, journal with article template/gating, FAQ, booking disabled/verified states, privacy and 404.
5. Add restrained motion, responsive polish, metadata and sitemap rules. Do not add decorative dependencies before the static composition is strong.
6. Test QA checklist; fix meaningful failures. Produce website/docs/BUILD-REPORT.md with implemented routes, commands/results, screenshots and remaining data/integrations.
7. Prepare production configuration only after data is confirmed. Deployment is a separate user instruction.

Handover should explain how to edit profile, approve records, add a service, set clinic destinations and change theme tokens. Include real local setup commands matching installed package manager and dependencies. No claim of CMS or booking integration unless implemented and verified.
