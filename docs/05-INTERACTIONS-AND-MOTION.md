# Interaction and motion specification — «للنظرة تفاصيل»

## 1. الحركة كجزء من الفكرة التحريرية
- **ظهور العنوان كوحدات نصية كاملة:** يظهر السطر الأول «للنظرة» يليه السطر الثاني «تفاصيل.» والتعريف المهني كوحدات نصية كاملة مترابطة بحركة قصيرة (`translateY` + `opacity` خلال `550–700ms`) دون فصل الحروف العربية أو التباعد بينها.
- **كشف الصورة البانورامية مرة واحدة عند الدخول:** كشف بصري متزن للصورة البانورامية عند الدخول (`clip-path` / `scale(1.03 -> 1)` مع `opacity`) يعمل مرة واحدة فقط.
- **انتقالات الفصول (`ScrollReveal`):** انتقالات بسيطة وواضحة عند ظهور الفصول أثناء التمرير الطبيعي دون تثبيت طويل للأقسام أو تعطيل التمرير.
- **تفاعل روابط المقالات والصور:** انتقال خطي واضح على عناوين وروابط المقالات مع استجابة بصرية هادئة للصور داخل إطاراتها المستقيمة.
- **الممنوعات وإمكانية الوصول:** لا توجد مؤثرات تتبع الماوس أو حركة عيون أو رمش مصطنع. يبقى المحتوى كاملًا ومقروءًا عند تفعيل `prefers-reduced-motion: reduce` أو تعطيل الجافاسكربت.
